# AI assistance

AI tools may help draft, edit, test, debug, and review this documentation site.

A maintainer remains responsible for every accepted change. Contributors must understand and be able to explain their changes, verify technical claims against the matching OpenMeshTak release, run the repository checks, and have the right to submit all text and assets they contribute.

AI output does not replace real-client compatibility testing, security review, license review, or maintainer acceptance.
