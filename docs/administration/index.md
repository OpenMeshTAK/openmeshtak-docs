# First administrator

1. Start OpenMeshTak.
2. Read the short-lived bootstrap token with `docker compose logs core`.
3. Open the public HTTPS address.
4. Enter the token and create the administrator account.
5. Sign in and review registration, email, map, and TAK server settings.

Use a unique username and strong password. The username is also used for TAK enrollment. You can add a passkey after setup.

Keep public registration closed or invite-only unless anyone should be able to create an account.
