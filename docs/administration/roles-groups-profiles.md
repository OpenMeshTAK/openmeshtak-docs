# Roles, groups, and profiles

## Event roles

Roles describe participant functions. A role can override the group's default TAK role, for example `Team Lead`, `Medic`, or `RTO`.

## Event groups

Groups define:

- the callsign format;
- TAK team color and default role;
- optional external TAK group names; and
- the Meshtastic short-name prefix.

A prefix such as `B` produces member names such as `B1` and `B2`.

## Resolved profile

The resolved profile shows the final callsign, TAK identity, Meshtastic identity, channels, and configuration revision for one participant. Generated files use this result.

Check the preview before activating an event. Resolve callsign and mapping conflicts first.
