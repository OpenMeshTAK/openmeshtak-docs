# OpenMeshTak

OpenMeshTak is a self-hosted platform for configuring event participants, TAK clients, Meshtastic radios, and mission data.

An administrator defines an event once. OpenMeshTak then creates the correct callsign, TAK settings, Meshtastic settings, channels, and downloads for each participant.
