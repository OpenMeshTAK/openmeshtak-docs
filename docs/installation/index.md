# Installation

OpenMeshTak Core `0.1.9` is deployed as one container. It serves the Web app, REST API, certificate enrollment, Marti Data Packages, and live CoT.

1. [Install with Docker Compose](/installation/docker).
2. Configure [HTTPS and the reverse proxy](/installation/reverse-proxy).
3. Check the [TAK ports](/installation/tak-ports).
4. Set up [backups and upgrades](/installation/backup-upgrade).
