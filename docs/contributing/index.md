# Edit these docs

Clone the documentation repository beside the other OpenMeshTak repositories, then run:

```sh
pnpm install --frozen-lockfile
pnpm docs:dev
```

Edit Markdown below `docs/`. VitePress updates the local site while you work.

## Writing style

- Lead with what works or what the reader should do.
- Keep instructions short and task-focused.
- Put important limits in a warning box.
- Use exact commands and field names.
- Do not include test diaries or internal planning notes.
- Do not claim compatibility for an untested client version.

## Check your work

```sh
pnpm check
```

See `CONTRIBUTING.md` in the repository root for API-reference updates and repository boundaries.
