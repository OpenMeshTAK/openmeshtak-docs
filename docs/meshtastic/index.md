# Meshtastic configuration

OpenMeshTak Core `0.1.9` includes the `meshtastic-2.8` profile. Firmware `2.8.1` build `8e6a88d` is confirmed working with `.cfg` import in the Meshtastic Android app.

## Configure an event

1. Choose the recommended firmware.
2. Save the profile settings.
3. Create the primary and secondary channels.
4. Set channel audiences and secret key holders.
5. Publish the event configuration.
6. Download the member-specific `.cfg` file.

Only settings supported by the selected firmware profile are written. Only tested firmware versions show **Tested on a device**.

The Meshtastic `.cfg` import on iOS is not yet listed as confirmed.
