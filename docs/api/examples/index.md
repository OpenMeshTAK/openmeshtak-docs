# API examples

Each example solves one task with plain `curl` calls; where the [SDK](/sdk/) has a method, a second tab shows the same call in TypeScript. The `curl` examples use the `OMTK_ORIGIN` and `OMTK_API_KEY` variables from [API basics](/api/#first-request); the SDK examples use a `client` as in [SDK basics](/sdk/#create-a-client). Replace placeholder IDs with the IDs returned by earlier calls.
