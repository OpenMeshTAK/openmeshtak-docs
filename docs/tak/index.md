# TAK

OpenMeshTak includes certificate enrollment, Marti Data Packages, and live CoT.

| Service | Default port |
| --- | ---: |
| Enrollment | `8446` |
| Marti | `8443` |
| CoT | `8089` |

Use the setup made for the participant's app:

- [ATAK on Android](/tak/atak)
- [iTAK on iOS](/tak/itak)
- [Data Packages](/tak/data-packages)

The event is the live CoT boundary. Devices in the same active event can exchange CoT; devices in different events cannot.
