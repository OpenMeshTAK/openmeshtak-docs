# Data Packages

## Create and publish

1. Create a Data Package.
2. Add or import mission content.
3. Choose its audience.
4. Choose automatic installation on enrollment, connection, both, or neither.
5. Publish the revision.

Drafts are not delivered. Publishing an unchanged draft keeps the existing revision.

## Delivery

ATAK and iTAK can list and download packages from OpenMeshTak. Automatic installation and revision updates are supported by the confirmed client versions.

Participants can also download packages from the Web for manual import.

## Supported content

OpenMeshTak works with mission objects, CoT, KML/KMZ, and ATAK Data Packages. Uploaded files are treated as untrusted and remain behind authorized download routes.
